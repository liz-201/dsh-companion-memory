# dev.15 成人非露骨亲密表达

该能力默认关闭。安装 dev.15 后，可在「插件控制台 → 成人亲密吸引」查看状态。开启需用户本人勾选本机启用、自己成年、当前角色成年，再确认保存；开发和自动化不会替用户填写。角色声明绑定当前 persona，更换角色后需重新确认。

在上述范围内，当前本人对角色说“想抱你”“今晚想你了”等自然表达可作为线索，不需要记忆固定命令。引用、台词、假设、转述、否定、第三方和技术请求不会作为正向线索；“多聊一会”、感谢和好感度不会自动加分。该数值是角色表达的工程状态，不是对用户欲望、身体或心理的测量。

本版包含：

- 独立来源账本和衰减投影；重复读取、重试与多窗口不会重复加分，来源撤回或修订后重算。
- 低强度心动和更亲近的非露骨表达方向；仅用于当前私聊闲聊，邀请十分钟有效，同一来源最多一次，实际送达后至少间隔二十分钟。
- 明确停止在真实入站立即生效，生成途中停止会阻断旧计划。界面也提供「立即停止这类表达」。停止后旧记忆、时间经过、好感度和切窗口都不能自动恢复。
- 恢复需要在本机界面明确确认所有已知停止记录；只允许恢复之后的新证据，不让旧轨迹反弹。
- 停止记录随 portable v7 同步，新发现的停止使另一台机器禁用。离线设备在同步完成后才知道停止；本机开关、成年声明和恢复许可不导出，各机单独设置。

不向任务、结构化输出、安慰支持和创作注入该模块的方向，不增加主动联系频率。表达限于非露骨范围，不生成具体性行为、性器官或身体刺激描写，不把意愿当同意，不忽略拒绝，不声称已发生现实接触或模型具有真实生理需求。

## 数据与升级

追加 schema 10，仅新增最小停止控制表，既有迁移不改。删除原消息清除原文及其普通证据，停止控制仍保留；删除整个主人数据按已有全量删除流程清除。新便携文件为 v7，最低读取器为 `0.3.0-dev.15`；两台电脑均应升级后再交换新包。旧 v1–v6 继续支持，旧格式伪装携带新语义会被拒绝。

升级前保留一致性备份。旧程序不应读取升级后的数据库；回退使用升级前备份，并单独保留升级后新增原始记录用于后续恢复。

## 验证边界

自动回归使用临时数据库、固定时钟和假宿主，覆盖真实观察入口、保存与投影、Desktop 流与消息落库、QQ accepted/unknown 回执、跨窗口与角色隔离、异步停止竞态、鉴权 HTTP 控制台，以及便携合并、删除和停止传播。具体运行结果以本次发布的验证记录为准。

没有在生产库代开启本模块，也没有代填成年声明。仍需用户开启后的真实模型表达质量、真实 QQ 到达和另一台实体电脑体验验收；自动测试通过不代表真实模型每次必说某一句，也不保证正则覆盖所有自然语言变体。
