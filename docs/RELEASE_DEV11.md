# 0.3.0-dev.11

2026-10-29。本版完成 DSH 的表达调节包与实际运行时接线，并修复导入后技术协作消息抬高最新本人消息序号的问题。

## 已实现

- DSH 提交的 `regulateExpression()` 进入 `ExpressionRuntime.plan()`，前台和桌面表达守卫使用同一调节结果。高兴不因唤醒度高被压低，恐惧或悲伤不转为惩罚，支持模式优先回应用户的困难。
- 便携导入重建 `latest_inbound_seq` 时使用与真实入口相同的本人来源门禁。
- 保留 dev10 的统一主人记忆、来源隔离、当前评价策略、关系三轴、情绪时间线和受保护收尾接口。
- 修正确定性回放工具：使用真实 QQ 本人入口，模型用量仍标为 `replay`。不为测试放宽生产来源门禁。

## 兼容与安装

数据库仍为 schema 9；已应用的 008 原文不变。本版未新增数据库迁移。

便携格式仍为 v5，最低读取版本仍为 dev10。dev9 无法读取 v5 云端快照；两台电脑都应升级至 dev10 或之后版本。旧格式 1–4 继续可以由新版本读取。

更新时同时修改 profile 的 `package.json` 本地依赖和 `node_modules/dsh-companion-memory` 目录链接，二者指向同一份独立发行目录。保留一致性数据库备份、旧发行目录和原配置。随后重新加载插件或重启 DSH，并通过本机 `/companion-memory` 的实际版本确认生效。
