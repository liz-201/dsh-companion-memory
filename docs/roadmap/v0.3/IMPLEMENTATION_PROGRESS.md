## 工程决定补充

1. 熟悉感除原有关系事件外，在表达投影中加入真实用户接触次数/UTC日期数的有界估计：`.1 + .45*(1-exp(-messages/60)) + .25*(1-exp(-days/14))`。与持久familiarity取较大值，只影响表达投影；不自动增加trust/affection，不计助手消息，不改稳定人格。它不是心理学公式。删除原话的tombstone会使缓存重建。
2. 后台extract可以安全跨机恢复，因为只读原话、写记忆且有幂等；执行中的主动消息不能跨机恢复发送。
3. 旧naturalExpression=false保留diagnostic兼容态，不静默替用户改回enforce；该状态不能作为本版正式验收结果。
4. 未知送达不重发。离线文件拷贝不能提供分布式互斥；新机默认沿用原设备的主动归属，接管须同步/暂停旧机。
5. 正则与字面保护不能证明所有改写语义等价。语义结果的unknown会保留在诊断中；不能由此宣称“完全没有AI味”或内容保真已经达标。
