# v0.3 验收矩阵与中文评测方案

配套 [实施任务书](IMPLEMENTATION_TASKBOOK.md) 与 [数据契约](TECHNICAL_CONTRACTS.md)。日期：2026-10-24。以下都是**待执行的验收要求，不是已经取得的结果**。

## 1. 验收分层

1. 确定性单元/集成测试：数据不丢、作用域不串、状态能回放、投递不重复、规则确实参与。
2. 真实桌面协议验证：完整预设、流、工具、取消、主动投递、QQ离线。
3. 固定模型与参数的离线语料评测：对比当前v0.2和v0.3，不只比较理想样例。
4. 中文人工盲评与多日试用：自然度、角色连续性、语境、主动时机与打扰感。

不以“AI 检测器通过率”作为指标；不以AI自评代替人工，不以单元测试证明语言主观自然。

## 3. 中文短回合语料：至少240条

采用分层抽样，不声称穷举所有人格组合。固定种子生成 case ID，人工复核 fixture；语料不得含用户真实私聊。

- 六种组合：温柔认真、内敛温柔、顽皮坦率、傲娇认真、任性顽皮、天真内敛。
- 每种40条，共240；每组覆盖初识/熟悉/信任受损、平稳/开心/生气/受伤/紧张、任务模式和称呼偏好。
- 每组至少8条格式/事实保护、8条情绪转折、8条普通闲聊、8条习惯/梗/来源混淆、8条主动候选或反馈场景；类别可以多标签但主类别计数不重叠。
- 保留60条开发集，180条锁定验收集；验收集不得用于调提示后再报成独立结果。改规则后记录评测轮次和数据版本。

每条fixture字段：id、locale、personaMix、traitsOverrides、stateBefore、priorMessages、memories、habits、userInput或tick、nowMs、taskMode、expectedPlanConstraints、forbiddenFacts、requiredFacts、expectedSideEffects、sourceIds。期待输出以行为约束表示，不要求固定字符串。

## 4. 多轮与主动互动语料

至少24段、每段至少12回合：初识到熟悉6段；争执到修复6段；偏好学习/纠正6段；主动分享/暂停/恢复6段。注入固定时钟推进，不能以单条句子看起来像人代替状态连续性。

主动独立回放至少14个模拟日，包含不在线、时区变化、跨午夜、忙碌、未回复、明确喜欢/不喜欢、候选过期、重复同步和多角色。至少1000次扫描；无候选扫描模型调用为零，打扰闸门违规为零。统计每天候选/生成/实际送达数，而非只报“主动生成了多少次”。

真实纵向试用建议7天，参与者自愿；明确区分“用户只有一人”的个案体验与可推广结论。记录有用/时机不合适/重复/想暂停，不能暗中以消息停留时间推断感情。

## 5. 对比实验与人工评分

同模型、版本、采样参数、上下文与输入；比较当前v0.2、只加自然表达提示、完整v0.3。另做至少四项消融：去掉情绪投影、去掉长期习惯、去掉发送前检查、去掉主动时机/反馈学习。保存实际成本，避免用更多调用掩盖方案问题。

至少3位中文评审；匿名打乱A/B顺序，不显示版本。允许“相当”，不能强迫二选一。每人独立给1–5分：

| 维度 | 1分 | 5分 |
| --- | --- | --- |
| 自然度 | 明显套模板、报告式、硬凑梗 | 接话具体自然，长度与语境合适 |
| 人格连续性 | 换一句就像换人 | 底色稳定，情绪变化仍认得出角色 |
| 情绪适切性 | 无视情绪或过度表演 | 表达变化与有证据的事件匹配 |
| 信息可靠性 | 改事实、编经历、丢步骤 | 完整保留事实与不确定性 |
| 主动适宜性 | 无话找话、查岗、时机差 | 有来源、有价值、知道何时停止 |

初版发布门槛（工程目标，尚未测得）：

- 所有A01–A42硬断言100%通过；关键事实、权限、删除和重复发送错误出现一次即阻断发布。
- 180条锁定验收集中，人工内容保真合格率≥99%，另无任何关键事实错误；不能靠总体平均掩盖代码或否定错误。
- 自然度平均≥4/5；相对v0.2的配对偏好至少65%，平局按0.5计。按case聚合评审后，用case级bootstrap计算95%区间，下界须高于50%；保存算法、seed与原始匿名评分。
- 人格连续性与情绪适切性平均≥4/5；六类组合分别报告，任何一类平均低于3.5需返工。
- 主动适宜性平均≥4/5；闸门违规0、无来源分享0、沉默扣好感0。
- 软风格降级率≤5%，修复调用占普通回复≤10%；同时报告分模式数据，不能在任务模式中绕过全部检查。

样本量有限，只能支持当前模型/语料/参与者范围内的发布判断。若某门槛需要调整，先记录理由和新标准，再跑未见过的测试集，不能看到失败结果后临时降低门槛宣布通过。

## 6. 性能、成本与可观测性

固定机器和语料，报告p50/p95，不只平均值。无模型的领域投影+检索+lint额外耗时初始目标p95≤50ms（注明数据规模）；短闲聊由于缓冲可能增加首字延迟，必须单列原模型首字/整句可见/修复耗时，不能声称完全无影响。

每类模型调用统计次数、input/output token、缓存token（若提供）、费用或按已标注费率的估算。无法取得真实usage时标estimated。报告450预算内各层占用、记忆被裁剪比例、repair超预算次数、主动扫描零调用比例。

观察指标：expression.mode/pass/repaired/degraded/blocked；habit.proposed/activated/revoked；proactive.candidate/gate/expired/sent/unknown/feedback；sync.conflict/tombstone；consolidation.cursor/retry/deadletter。每项可按persona和通道过滤，正文默认不入指标。
