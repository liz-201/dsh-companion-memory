# 成本与延迟说明

2026-10-24，开发版；实际付费模型usage和金额尚未测得。

- 人格、任务模式、表达规划、接触熟悉度、习惯检查和普通lint在本地运行，不调用模型；1000轮本地表达链路p95约0.40ms。
- 默认上下文预算仍450个估计token；若旧预算容不下核心策略，配置解析提升到实测核心长度所需的最低值。估计token不能当作供应商账单。
- 现有每条用户消息的后台观察仍会产生独立模型调用；本次没有把这笔成本隐藏为零。整理按批触发。
- 只有发现需修复的问题才尝试修复模型，每回合最多一次，当前角色每天默认最多十次；额度在调用前用数据库事务预留，避免并发超额。未知usage记录为unknown。
- 无候选的主动扫描不调模型；14天模拟1008次扫描中13次有候选生成。配置外部分享来源后另有受限HTTP读取，不自动扫描用户文件或浏览历史。
- 短回复缓冲会增加首段可见延迟，修复调用可能再增加等待。真实首字/整句/修复耗时尚未测得；本地毫秒数不能替代网络体验。

后续报告须按main/extract/consolidate/proactive/repair分别列次数、input/output/cache token和费用，标明模型、费率日期、样本量。当前没有凭据可用性或真实模型成本结论。
