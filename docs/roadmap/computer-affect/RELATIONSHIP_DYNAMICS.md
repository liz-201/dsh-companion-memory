# 亲近、接近动机与短时投入的来源回放

2026-10-29。状态：纯域模块，宿主接线与生产验收另记。入口是 `src/domain/relationship-dynamics.ts` 的 `projectRelationshipDynamics(events, nowMs, parameters?)`。

`intimacy` 表示缓慢累积的计算亲近度；`desire` 只接受明确的接近／拉开距离动机；`passion` 表示亲近正向变化或明确接近动机产生的短时投入。三者都是 `[0,1]` 工程坐标，不是心理测量、主观体验、同意或现实关系状态。它们不取代旧 `Relationship` 的好感、信任、尊重、熟悉度和未解冲突，也不生成承诺。

## 输入和来源责任

每个事件为 `{ sourceId, atMs, intimacyDelta?, pull?, revision?, status? }`。`atMs` 是原始来源的整数 Unix 毫秒时间，`intimacyDelta` 和 `pull` 均在 `[-1,1]`。缺失表示没有该项证据，不从 `appealingness`、聊天频率、沉默或旧包中补猜。宿主必须先校验主人身份、当前有效原文、引用和来源范围，再构造事件；纯函数不能凭一个字符串 ID 验证这些事实。

`intimacyDelta` 是亲近方向的有界输入信号，由 `intimacyGain` 调节增量。如果宿主传入的已经是实际旧关系增量，可以显式使用 `intimacyGain: 1`，不要再次无意缩小。`pull` 是独立动机，不能拿「喜欢某物」代替。普通中性消息可仅有 ID 和时间，不会提高任一轴。

同一 `sourceId` 只使用最高有效 `revision`，默认版本为 0；同版本的语义相同副本只算一次，同版本内容不一致则抛出 `Conflicting relationship source revision`，交给上层保留冲突，不能按导入顺序选一份。更高版本完全替代旧事件。`status: 'retracted'` 的最高版本移除该来源，删除后的宿主也可直接不再提供该来源。

未来事件在选择版本前排除，不能影响过去的投影；更正记录应使用原始来源时间，不能把后台处理时间伪装为事件时间。不同来源同一毫秒仍是不同事件，按该毫秒聚合后处理，避免 ID 顺序影响边界裁剪。来源用时间、ID 确定性排序，乱序下载和重启后读入相同材料产生相同结果。

## 有界状态变化

- 亲近度只有已提供的正负 `intimacyDelta` 会改变。空闲时间没有扣减项；本模块不修改信任，也不把未回复解释为拒绝。
- 接近动机只由 `pull > 0` 推动，随后指数回落；与当前亲近度水平独立。明确负 `pull` 降低两项短时状态，同一毫秒出现矛盾信号时撤离信号优先，不用正向信号抵消边界。
- 短时投入由实际正向亲近变化和明确正 `pull` 推动，随后更快回落。亲近度维持高位但只有中性互动时，它仍会下降。负向亲近变化会阻止同批的正向短时投入增益，并降低或不改变它；不使用 `abs(d intimacy/dt)`，不会把受伤、疏远奖励成浪漫投入。
- 全部来源回放完成后只做时间投影，读取不改输入、不写状态。禁止把返回的投影再当新来源送回函数，否则会失去来源级幂等性。

输出包含 `atMs`、三个坐标、按时间排列的有效信号 `evidenceIds`、有效唯一来源数 `sourceCount` 以及算法版本 `relationship-engineering-v1`。中性事件计入来源数，不进入情感证据列表；撤回和未来事件均不计入。宿主注入提示词时可另做证据预算，原始来源不能因此丢失。

## 参数与证据口径

默认亲近初值 `.15`、亲近信号增益 `.05`、接近动机增益 `.25`、半衰期 `180` 分钟、短时投入半衰期 `60` 分钟、亲近增益 `2`、动机增益 `.2`、撤离损失 `.75/1`、疏远损失 `2` 均是**待校准的产品初值**，没有声称这些系数来自人群研究。参数覆盖须有限且在声明范围内，错误时间、NaN、Infinity 和越界信号抛受控错误，不让污染扩散到状态。

本模块没有把任务书中的「亲近导数绝对值」当作实证结论，也没有设「亲密越高欲望越低」。严格的心理学主张和真实使用体验仍需单独核验；本文件只说明可执行的工程语义。

## 验证和限制

在本模块所在开发／整合工作树执行：

```text
node scripts/build.mjs
node --test tests/unit/relationship-dynamics.test.mjs
```

固定时钟用例涵盖稳定高亲近回落、亲近增长与下降、明确接近与撤离、重复与更正、撤回、同毫秒不同来源、逆序、未来、坏参数、只读和一万条混合来源重建。纯函数通过不等于提取模型已正确输出 `pull`、实际 DSH／QQ 已使用三个轴、云同步已迁移或真人自然度已验收；这些由宿主接线和独立链路测试证明。
