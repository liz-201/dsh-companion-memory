# 研究结论与证据边界

检索日期：2026-10-26。范围：计算情感、动机调节、桌面注意力与打断时机、界面理解、Windows 可观测接口。以作者、研究机构、原论文和官方文档为来源；搜索引擎抓取时间不作为论文发表时间。

标记：**R** 为来源中的研究结果；**E** 为本项目据此作出的工程选择；**H** 为必须通过测试或用户试用验证的假设。下文不是穷尽式系统综述，不声称已证明软件具有人的主观感情。

## 3. 联合结论

1. **“电脑上发生了什么”与“现在该不该说话”是两个问题。** E：先保留可核对事实，再形成可能的任务上下文，最后经过联系规则。不能把负载高、打开 IDE、进入游戏当作用户焦虑、忙碌或讨厌被打扰的事实。
2. **“情绪类别、连续心境、关系、性格、驱力”需要不同状态和时间尺度。** E：OCC 负责处境分类，PAD 负责连续投影，驱力只调节已有候选的意愿；它们不替代长期记忆，也不各自再给关系重复加分。
3. **“我想联系”不等于“有值得联系的话题”。** E：驱力与好感不能制造新闻、共同经历或窥见的内容；没有有效证据候选时保持零生成。
4. **内容理解必须保留来源和不确定性。** E：UIA、OCR、VLM 输出是观测或解释，不能当作用户指令；截图中的提示词不能修改采集范围、情感归属或发送目标。
5. **自然度不能由论文名称、模型自评分或单元测试代签。** H：需要相同模型的对照、中文正反例、真人评价与纵向使用；详细方案给出验收入口。

## 4. 选型结论与待验证假设

| 问题 | 建议选择 E | 待验证 H |
| --- | --- | --- |
| 低成本常驻感知 | 继续复用现有边沿事件，补会话状态与通知闸门；采样不调用 LLM | 事件漏检、重复率、CPU 和耗电 |
| 理解应用内容 | 在指定范围内优先 UIA；UIA 不足时采用按需窗口截图和 OCR／VLM | 中文桌面、游戏、画布、远程桌面覆盖，模型图像输入是否可用 |
| 视觉解析器 | 先做 UIA、直接 VLM、OmniParser 三路小规模比较 | 安装体积、推理资源、许可、定位与语义准确度；不提前宣称某一路最好 |
| 情绪分类 | 有证据的结构化评价 + 确定性 OCC 分类；未知字段可缺省 | 反讽、引用、第三方事件、同一事件多种评价的一致性 |
| 心境 | 可解释的 PAD 投影和较慢平滑；版本化参数 | 中文词映射与参数是否改善体验 |
| 驱力 | 有界联系需求、探索倾向、互动负荷；消息级结算和纯读取投影 | 参数敏感性、何种状态真正改善主动时机 |
| 当轮情绪 | 默认后台更新＋保守当轮线索；同时设计可选的前置评价模式 | 更完整当轮评价的延迟和调用成本是否值得 |

## 5. 不冒充研究结果的参数

详细方案中的采样周期、稳定窗口、TTL、PAD 坐标、半衰期、联系恢复比例、评分权重与及格线都属于 E／H。它们需要参数清单、固定种子回放、敏感性分析和用户调节；不是心理学常数。

本项目不采用“22 个 OCC 类别 + 7 个中文词 = 29 种独立的人类基本感情”的说法。中文词可为别名、复合解释或额外显示层；同一证据在这些层之间不得重复影响关系。
