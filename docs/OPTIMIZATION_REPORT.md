# 0.1.1 优化与验证记录

日期：2026-10-23（北京时间）。本记录覆盖本轮代码修复；不将离线测试视作真实模型或 QQ 联调。

## 已修复

- 情感事件允许没有冲突 episode，感谢等正面事件不再触发外键错误。事件、episode 与快照在同一短事务提交，失败整批回滚。
- `/fish correct` 按事件时间重放剩余有效事件；关系重置保留明确的新基线。每日变化按用户时区累计绝对值，并计入实际使用的三位小数精度。
- 预算覆盖实际 system、当前 user、策略提示与消息封装。先裁剪历史与检索，当前输入仍超限时保留原文、明确拒绝生成，不静默截断材料。
- 普通聊天在 `</say>` 闭合时发送一次。发送前写入 outbox；unknown 保留核对，不退回另一条默认发送路径。尾部断流保留已发正文。
- 提醒请求先验证来源、时间并提交，再回复成功；校验失败给出确定性失败说明。确认提醒不占闲聊额度，不受自发联系开关影响。
- 修复主动开关修改冻结配置的问题，开关跨重启恢复。恢复已知会话目标；未回复自发消息会暂停后续闲聊。
- 按人格预设分别缓存提示词；每次调用重新解析模型 route。依据宿主声明映射关闭思考，识别终止错误和取消。
- 不再向插件全局注册人格或内部协议。本人白名单在入站落库前检查，Web 中未绑定的 `/fish` 入口拒绝访问。
- 增加持久化、owner-only 的 `review begin friendly|tense|after_conflict` / `review end`。沙盒使用独立 principal/conversation，禁止真实提醒和自发调度。
- 巩固按轮次门槛和持久游标选择增量，检查点保存结构化内容；助手文字不能作为用户事实证据。
- 提供 `dsh-onebot-qq@0.9.3` 可选接入补丁、版本与锚点检查、SHA-256 备份和冲突时拒绝覆盖的回滚脚本。
