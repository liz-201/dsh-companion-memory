# 插件控制台与主动联系

适用版本：0.3.0-dev.5。通过 DSH 官方 `webserver/index-inject` 扩展接口增加「🐟 插件控制台」入口，不修改宿主安装文件。升级后重新构建并重启 DSH，点击窗口右下方的按钮即可打开本机控制台；日常使用不必记命令。原有记忆管理页地址也可直接打开新版控制台。

## 可以在界面做什么

| 区域 | 操作 |
| --- | --- |
| 总览 | 选择本人的角色与会话，查看好感、信任、熟悉度、情绪与最近变化原因 |
| 主动联系 | 开启/暂停、预览草稿、立即检查、每日额度、间隔、静默时段、未回复暂停、适应性频率、设备接管 |
| 兴趣分享 | 设置当前角色兴趣，以及允许读取的 HTTPS 网页/RSS/Atom 来源 |
| 电脑感知 | 总开关、应用切换、网卡连接恢复、电量/资源异常、空闲后返回、指定目录变化，查看事件或撤销待发话题 |
| 性格与习惯 | 三种基础性格、十二个维度、八种模板组合，查看或撤销学到的交流习惯 |
| 记忆 | 查找、手动记住、确认后遗忘；选择情感事件并更正判断；更正主动联系的反馈归因 |
| 提醒 | 添加有明确时间的提醒，查看或取消提醒与待续事项 |
| 导入导出和百度网盘 | 下载完整记忆文件、选择文件导入、百度官方授权、立即同步、断开连接 |
| 维护 | 一致性备份、暂停/恢复后台整理、自检、表达检查记录、隔离试聊、确认后重置关系 |

角色的记忆、情绪、性格和兴趣按当前所选角色隔离。联系规则、内容来源与电脑采集范围是本机设置；角色兴趣随记忆迁移。本机文件夹和采集设置不随记忆迁移，换电脑后重新选择。

“预览”会在符合条件且有真实话题时生成草稿，不入发送队列；“现在检查一次”会按真实规则安排发送。默认的主动联系开关保持原有选择，不会因升级自行开启。明确设定的提醒沿用现有规则，可在暂停闲聊时照常提醒。

## 电脑事件如何形成对话

电脑感知默认关闭。在控制台勾选需要的范围，再点击「保存主动联系与电脑感知设置」，设置立即生效并在本机保存，无需再次重启。

- Windows 采样真实空闲时长与前台应用的进程名；资源读取 CPU、内存和可用的电池电量；网络恢复表示本机网卡重新有地址，不保证能访问互联网。
- 文件夹监听只覆盖明确填写的目录，非递归，只记录目录名和文件名；跳过 `.env`、凭据目录、私钥等噪声。文件正文不读取。
- 首次采样仅建立基线。应用切换、连接恢复、资源/电量越界与空闲后返回均依据实际变化；电量与资源异常有恢复阈值，避免连续报告同一异常。
- 应用/文件变化只有匹配用户已有偏好或当前角色兴趣才形成话题。系统异常和真实的空闲返回可成为简短关心的依据，仍需经过话题评分与发送检查。
- 事件优先关联最近联系且仍可用的本人桌面会话，不向联系人列表广播。事件线索限本机、短期有效，不伪装成用户说过的话，也不作为可迁移的用户记忆。
- 不采集屏幕、窗口标题、键盘内容、剪贴板、浏览历史或文件正文。关闭采集后停止监听并撤销相关待发消息；也可单独点击「撤销电脑事件话题」。

这不是遍历电脑全部内容的监控器；无法读取或不支持的探针显示未知或错误。没有线索时保持安静。

## 兴趣分享与频率

兴趣分享仅访问用户设置的来源，最多四个 HTTPS 地址；每个来源通常隔十二小时重新读取，限时五秒、正文上限 100 KB，最多处理十二篇条目。逐篇匹配用户偏好或角色兴趣，分享保留来源链接。网页内容只作不可信材料，读取失败不编造替代内容。角色感兴趣不代表用户也喜欢它。

默认基础额度每天两条、至少间隔一百八十分钟。开启适应性频率后，好感高于 0.5 且当前主动性、社交活力、活泼度的平均值高于 0.5 才会增加额度、缩短间隔；怨气会削弱增加幅度。默认极限是每天四条、至少九十分钟，可在控制台调整或关闭。

额度为零仍然不发。静默、正在对话、用户表示忙、未回复暂停、设备归属和话题有效期始终检查，发送前再次复核。不同角色不共享好感度来获得额外额度；全部角色仍受同一实际发送间隔和总量约束。

## 验证与使用边界

本轮独立发布快照全量 293 项通过，0 失败、0 跳过；已生成开发版安装包。原生进程激活后的检查另行记录，不能与独立回归混同。

新增回归涵盖真实 HTTP 控制台按钮脚本、角色隔离、设置重新加载、危险操作确认、提醒/性格/备份操作；实际 DSH Cordis 中的晚加载、卸载和重新加载；真实 Windows 状态探针及临时目录监听；事件证据过期、撤销与迁移隔离；RSS/Atom 文章链接；适应性额度和发送前限制。另修复原有 `remember` 因缺少来源证据而无法保存的问题。

自动化验证不等同于人类对自然度的验收。多日陪伴效果、实际 QQ 收发和人工视觉验收按各自条件验证。运行中的 DSH 需要重启加载本轮代码，不能以本地构建成功代替原生进程验收。
